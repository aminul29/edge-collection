================================================================================
  GUMROAD SETUP GUIDE — Edge Collections Sidebar Pro
  For Bangladeshi Developers (Payoneer Payout)
================================================================================

This guide walks you through publishing your extension on Gumroad, enabling
license key generation, connecting Payoneer for payouts, and wiring everything
up inside your extension code.

--------------------------------------------------------------------------------
STEP 1: CREATE A GUMROAD ACCOUNT
--------------------------------------------------------------------------------

1. Go to:  https://gumroad.com
2. Click "Start selling" and sign up with your email.
3. Verify your email address from the confirmation mail Gumroad sends you.

--------------------------------------------------------------------------------
STEP 2: SET UP PAYONEER PAYOUTS (Bangladesh-Friendly)
--------------------------------------------------------------------------------

Gumroad does NOT support direct bank transfers to Bangladesh, but it fully
supports Payoneer — which does work in Bangladesh.

  a) Create a Payoneer account first (if you don't have one):
       https://www.payoneer.com

  b) In Gumroad, go to:
       Settings → Payouts → Connect Payoneer

  c) Follow the on-screen steps to link your Payoneer account.

  NOTE: Gumroad processes payouts every Friday once your balance reaches $10.
        Payoneer then transfers the money to your local bank in BDT.

--------------------------------------------------------------------------------
STEP 4: ADD LICENSE KEY MODULE  *** CRITICAL STEP — NEW UI ***
--------------------------------------------------------------------------------

Without this, buyers won't receive a key and in-app activation won't work!

Gumroad's UI has changed. The license key option is NO LONGER a simple toggle
on the product creation page. It is now a "Content Module" you must add from
within the product's Content tab.

Here is exactly how to do it:

1. In your Gumroad dashboard, open your product.
2. Click on the "Content" tab (the tab where you upload files).
3. Look for a button that says "+ Insert" or "Add a block" / "Add content".
4. Click it — a dropdown or panel will appear with block types.
5. Select "License key" from the list of modules.
6. A License Key block will appear in your product's content area.
   (You can drag it above or below your uploaded file — order doesn't matter.)
7. Click Save / Publish.

After this, every buyer will automatically receive a unique License Key
(format: XXXXXXXX-XXXXXXXX-XXXXXXXX-XXXXXXXX) shown on their receipt page
and sent to their email.

  TIP: If you don't see an "Insert" button, try scrolling down inside the
       Content tab. The button sometimes appears below the file upload area.

  TIP: If you still can't find it, make sure your product type is set to
       "Digital product" (not a physical product or a membership/subscription).

--------------------------------------------------------------------------------
STEP 5: GET YOUR PRODUCT ID AND URL
--------------------------------------------------------------------------------

1. Open your product in Gumroad editor.
2. Click "Share" or "View product page" to see the public URL:
      https://yourname.gumroad.com/l/edge-collections-pro
                                     ^^^^^^^^^^^^^^^^^^^^
                                     This part is the PERMALINK (Product ID)

3. Write down:
   - Your full Product URL:   https://yourname.gumroad.com/l/PERMALINK
   - Your Product Permalink:  PERMALINK  (just the slug after /l/)

   EXAMPLE:
   - Product URL:   https://aminul.gumroad.com/l/edge-collections-pro
   - Product ID:    edge-collections-pro

--------------------------------------------------------------------------------
STEP 6: UPDATE THE EXTENSION CODE
--------------------------------------------------------------------------------

Open the file:  sidepanel.js

Find lines 17–18 near the top of the file (inside the State Management block):

   BEFORE:
   ───────────────────────────────────────────────────────────────────────────
   const GUMROAD_PRODUCT_ID  = "edge-collections-pro";
   const GUMROAD_PRODUCT_URL = "https://gumroad.com/l/edge-collections-pro";
   ───────────────────────────────────────────────────────────────────────────

   AFTER (replace with YOUR actual values):
   ───────────────────────────────────────────────────────────────────────────
   const GUMROAD_PRODUCT_ID  = "YOUR_PERMALINK_HERE";
   const GUMROAD_PRODUCT_URL = "https://yourname.gumroad.com/l/YOUR_PERMALINK_HERE";
   ───────────────────────────────────────────────────────────────────────────

   IMPORTANT: GUMROAD_PRODUCT_ID must match the permalink EXACTLY.
              If the permalink is "xk8qw", the API will reject all other values.

After editing, save sidepanel.js and reload the extension in:
   edge://extensions/  →  find "Edge Collections Sidebar"  →  click "Reload"

--------------------------------------------------------------------------------
HOW THE LICENSE VERIFICATION WORKS (Technical Notes)
--------------------------------------------------------------------------------

When a user clicks "Activate" in the extension, the code calls:

   POST https://api.gumroad.com/v2/licenses/verify
   Body:
     product_id           = YOUR_GUMROAD_PRODUCT_ID  (the permalink)
     license_key          = KEY_PASTED_BY_USER
     increment_uses_count = true

Gumroad responds with:
   {
     "success": true,
     "purchase": {
       "email": "buyer@example.com",
       "refunded": false,
       "chargebacked": false
     }
   }

If success=true and refunded=false → Pro features are unlocked and the
key is saved in chrome.storage.local so the user stays Pro permanently.

The extension allows one activation per license key. Manual activation sends
increment_uses_count=true and rejects keys whose Gumroad purchase uses count is
greater than 1. Startup re-checks validate the saved key without incrementing
the usage count again.

If the key is invalid, refunded, or charged-back → the error is shown
in the paywall modal and access is denied.

No server required. Everything runs client-side from the extension.
